# 제품별 심층 분석 Cases

새 분석 대상은 제품별 폴더로 축적한다.

기존 `structure/`, `forensics/`, `systematic/` 문서를 대체하지 않는다.  
새 case는 한 제품을 볼 때 필요한 내용을 한곳에서 찾기 위한 **제품 중심 진입점**이다.

## 현재 Cases

- [Penpot](penpot/README.md)
- [AFFiNE](affine/README.md)
- [Microsoft MakeCode / PXT](makecode/README.md)
- [Padlet](padlet/README.md)

## 기본 분석 축

각 case는 가능하면 다음을 포함한다.

1. 제품이 푸는 핵심 문제
2. 사용자 기능/흐름
3. Product Boundary
4. Repository / Module 구조
5. Domain/Data model
6. 상태·저장·동기화
7. 확장 시스템
8. UX로 문제를 풀어낸 방식
9. 오류·복구·권한
10. 테스트
11. 장점
12. Trade-off
13. 재사용 가능한 패턴
14. Knol 적용
15. Source evidence
16. Unknowns

공개 source가 없으면 기술 내부 구조를 추정으로 확정하지 않는다.
