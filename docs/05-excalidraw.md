# 05. Excalidraw 분석

## 한 줄 결론

Excalidraw에서 가장 참고할 점은 많은 기능을 제공하면서도 **처음 화면에서는 도구 수를 제한하고, 선택한 대상에 필요한 속성만 보여주는 초보자 친화적 progressive disclosure**입니다. 여기에 local-first와 공개 JSON 포맷이 결합되어 있습니다.

## 왜 분석하는가

놀아트와 놀프린트는 기능이 늘수록 상단 버튼, 설정 패널, 전체화면 버튼, 도구 옵션이 동시에 노출되기 쉽습니다. 이때 기능은 많아지는데 사용성은 떨어질 수 있습니다.

Excalidraw은 전문 그래픽 툴보다 단순한 화면을 유지하면서도 실제 편집에 필요한 기능을 상당히 제공합니다.

## 확인된 사실

### A. 기본 도구는 제한적이고 명확

Excalidraw의 핵심 편집기는 선택, 사각형, 원, 다이아몬드, 화살표, 선, 자유그리기, 지우개, 텍스트 등 비교적 적은 기본 도구를 중심으로 구성됩니다.

도형 수십 개를 한꺼번에 도구막대에 노출하지 않습니다.

### B. 속성은 현재 선택에 따라 나타남

선택된 요소에 적용 가능한 색상, 선 스타일, 채우기, 글꼴 등의 속성을 보여주는 방식입니다.

핵심은 ‘설정 메뉴에서 모든 옵션을 찾게 하는 것’보다 **현재 작업 맥락에 맞는 속성을 바로 노출하는 것**입니다.

### C. local-first

공식 GitHub 설명에 따르면 excalidraw.com은 브라우저에 자동 저장하는 local-first 지원을 제공합니다.

사용자는 계정이나 명시적 저장 동작 없이도 편집을 이어갈 수 있는 경험을 얻습니다.

### D. 공개 파일 포맷

편집기는 `.excalidraw` JSON 파일로 내보내고 다시 열 수 있습니다. 결과물이 특정 서버에만 묶이지 않는다는 점이 중요합니다.

### E. 협업은 별도 기능층

excalidraw.com은 실시간 협업과 end-to-end encryption을 제공합니다. 반면 npm editor package 자체와 hosted app의 기능 범위는 동일하지 않습니다.

즉 **편집기 코어 / 앱 기능 / 협업 기능을 구분**해서 볼 필요가 있습니다.

### F. 라이브러리 개념

Excalidraw은 shape library를 지원합니다. 자주 쓰는 도형 묶음을 재사용할 수 있어 기본 도구막대를 과도하게 확장하지 않고도 확장성을 확보합니다.

## 핵심 UX 모델

```text
항상 보이는 것
  - 핵심 도구
  - undo / redo
  - zoom / canvas 기본 조작

선택했을 때 보이는 것
  - 해당 대상의 속성
  - 정렬 / 복제 / 삭제 등 관련 액션

필요할 때 여는 것
  - 라이브러리
  - 내보내기
  - 공유 / 협업
  - 고급 설정
```

이 3단 분리가 놀아트·놀프린트 UI를 정리하는 데 직접적으로 유용합니다.

## 놀아트 적용안

### 1. 상단은 ‘행동’, 사이드 패널은 ‘선택한 대상의 속성’

권장 구분:

상단:

- 선택
- 그리기
- 도형
- 텍스트
- 이미지
- 되돌리기/다시하기

선택 패널:

- 색상
- 선 굵기
- 채우기
- 투명도
- 정렬
- 복제/삭제

고급:

- 테셀레이션 변환
- 반복 배치
- 연결 규칙
- 내보내기 세부 설정

### 2. 설정 패널은 접을 수 있게

현재 작업과 관계없는 설정이 캔버스를 밀어내지 않게 합니다.

특히 태블릿에서는:

- 기본은 하단 sheet
- 탭하면 펼침
- 캔버스 터치 시 자동 축소

방식을 검토할 수 있습니다.

### 3. 도구 선택 상태를 더 명확하게

도구가 선택되었는지, 한 번만 사용하는지, 계속 사용하는지 명확해야 합니다.

예:

- 텍스트: 1회 배치 후 선택 도구로 복귀
- 연속 그리기: 계속 유지
- 도형: 옵션에 따라 ‘연속 배치’ 토글

### 4. 파일 포맷 독립성

놀아트 작품을 서버/브라우저 상태에만 묶지 않고 장기적으로 JSON export/import를 제공할 가치가 있습니다.

예:

```json
{
  "format": "knolart",
  "version": 1,
  "canvas": {},
  "objects": [],
  "assets": []
}
```

이미지는 별도 asset 패키지 또는 data reference 방식으로 관리합니다.

## 놀프린트 적용안

### 1. 처음에는 핵심 흐름만 보이기

놀프린트의 핵심 사용자 여정은 복잡하지 않습니다.

```text
이미지 넣기 → 자르기/맞추기 → 분할 수 선택 → 미리보기 → 인쇄
```

따라서 첫 화면에서 인쇄 고급 옵션, 맞물림 보정, 보조선, 세부 수치가 모두 보여야 할 이유가 없습니다.

### 2. 선택 기반 속성 패널

이미지를 선택했을 때만:

- 자르기
- 회전
- 맞춤
- 위치 초기화

분할 영역을 선택했을 때만:

- 4 / 9 / 16 / 25장
- 여백
- 맞물림

처럼 UI를 나눌 수 있습니다.

### 3. ‘안전한 기본값’ 강조

Excalidraw이 기본 도구만으로도 바로 시작할 수 있듯, 놀프린트도 사용자가 대부분의 옵션을 건드리지 않고 바로 출력할 수 있어야 합니다.

권장:

- A4 기본
- 세로/가로 자동 추천
- 양면 해제 상태 명확
- 기본 맞물림/여백 추천
- 문제 가능성이 있을 때만 경고

## local-first에서 가져올 점

자동 저장은 다음 계층으로 설계할 수 있습니다.

```text
1. 메모리 상태
2. IndexedDB draft
3. 명시적 export 파일
4. 필요 시 서버 공유
```

모든 작업을 서버 저장으로 시작할 필요가 없습니다. 학생 개인정보를 줄이고 오프라인 복구에도 유리합니다.

## 그대로 가져오면 안 되는 점

### 1. ‘단순한 외형’만 흉내내면 안 됨

Excalidraw이 단순해 보이는 이유는 기능이 없어서가 아니라 상태에 맞춰 기능을 숨기기 때문입니다. 버튼만 줄이고 기능 접근 경로를 없애면 사용성이 나빠집니다.

### 2. 무한 캔버스 제스처를 그대로 적용하지 않기

놀아트의 일부 활동이나 놀프린트는 작업 영역 크기가 학습/출력 목적과 직접 연결됩니다. 무한 캔버스는 선택 사항이어야 합니다.

### 3. 협업을 필수 전제로 하지 않기

학교 환경에서는 연결 불안정과 계정 문제가 더 큽니다. local-first 단독 사용이 완성된 뒤 협업을 추가하는 편이 좋습니다.

## 구현 실험

### 실험 E1 — UI inventory

현재 놀아트/놀프린트의 모든 버튼을 다음 3종으로 분류합니다.

- Always
- Contextual
- Advanced

그 뒤 Always가 7~9개를 넘지 않도록 재배치합니다.

### 실험 E2 — 선택 기반 inspector

하나의 공통 우측/하단 패널이 현재 선택 객체 타입에 따라 다른 옵션을 보여주도록 합니다.

### 실험 E3 — JSON export/import

작품 하나를 JSON으로 내보내 다른 기기에서 완전히 복원할 수 있는지 검증합니다.
