# 04. Artsteps 분석

## 한 줄 결론

Artsteps에서 놀아트가 가장 먼저 가져와야 할 것은 화려한 3D 모델이 아니라 **자유 관람과 안내 관람을 함께 제공하는 동선 설계**, 그리고 작품·설명·미디어를 공간 안의 동일한 ‘전시 객체’로 다루는 방식입니다.

## 왜 분석하는가

3D 전시실은 구현 자체보다 ‘사용자가 길을 잃지 않고 작품을 감상하게 하는 것’이 더 어렵습니다. 키보드 이동, 카메라 회전, 충돌, 작품 클릭, 설명 보기, 다음 작품 찾기가 동시에 요구되기 때문입니다.

Artsteps는 오랫동안 웹 기반 3D 전시 제작·관람을 제공해 온 서비스라 이 문제를 분석하기 좋습니다.

## 확인된 사실

### A. 제작 흐름이 공간 → 콘텐츠 → 이야기 순서

Artsteps 공식 사이트는 핵심 제작 흐름을 다음처럼 제시합니다.

1. 디지털 콘텐츠 업로드
2. 가상 공간 구성
3. guide point를 배치해 이야기/관람 흐름 구성

이미지·영상·텍스트·3D 모델을 같은 가상 전시 안에 배치할 수 있습니다.

### B. guide point가 중요한 기능

공식 사이트는 guide point를 공간 곳곳에 배치해 관람객에게 자신의 narrative를 보여줄 수 있다고 설명합니다.

이것은 ‘사용자가 알아서 돌아다니는 3D 공간’과 ‘큐레이터가 의도한 관람 순서’를 결합하는 장치입니다.

### C. 관람 결과물은 공유·임베드 대상

완성된 공간은 소셜 공유뿐 아니라 웹사이트에 embed할 수 있습니다. 제작기와 관람기가 분리된 결과물이라는 점이 중요합니다.

### D. 여러 기기에서 관람

Artsteps는 컴퓨터, 스마트폰, 태블릿, VR 환경에서의 탐색을 안내해 왔습니다. 따라서 입력 장치별 이동 UX를 고려한 서비스로 볼 수 있습니다.

### E. 현재성에 대한 주의

Artsteps 공식 블로그는 2025년에 ‘From Artsteps to Metasteps: The Next Chapter in Immersive Creation’을 별도 안내했습니다. 동시에 Artsteps 본 서비스는 현재도 VR 전시 제작·공유 기능을 안내하고 있습니다.

따라서 이 문서는 Artsteps를 ‘최신 3D 엔진 기술의 기준’으로 보기보다 **오랜 전시 저작/관람 UX에서 얻을 패턴**에 초점을 맞춥니다.

## 핵심 설계 모델

```text
Exhibition
 ├─ Space
 │   ├─ rooms
 │   ├─ walls
 │   ├─ floor
 │   └─ lighting/theme
 ├─ Artifacts
 │   ├─ image
 │   ├─ text
 │   ├─ video
 │   └─ 3D object
 ├─ Guide
 │   ├─ guide points
 │   └─ ordered route
 └─ Publication
     ├─ public/private
     ├─ share
     └─ embed
```

## 놀아트 3D 전시실에 가장 중요한 적용

### 1. 자유 이동 + 가이드 관람의 이중 모드

현재 3D 전시실이 자유 이동만 제공하면 사용자는 다음 작품이 어디 있는지 계속 판단해야 합니다.

권장:

**자유 관람**
- WASD/방향키/터치 조이스틱
- 마우스/터치 카메라 회전
- 원하는 작품으로 직접 이동

**가이드 관람**
- `다음 작품` 버튼
- 작품 앞 감상 위치로 부드럽게 이동
- 정면을 자동으로 맞춤
- 설명 카드 자동 표시 또는 선택 표시
- `이전 작품 / 다음 작품 / 자유 관람으로`

교실에서는 가이드 관람을 기본값으로 두는 것도 검토할 만합니다.

### 2. 작품마다 감상 포인트를 저장

작품 좌표만 저장하지 말고 관람 위치와 카메라 방향을 같이 저장합니다.

```json
{
  "artworkId": "a17",
  "position": {"x": 2.4, "y": 1.5, "z": -4.1},
  "viewpoint": {"x": 2.4, "y": 1.6, "z": -2.2},
  "lookAt": {"x": 2.4, "y": 1.5, "z": -4.1}
}
```

이 값이 있으면 `다음 작품` 이동, 미니맵 위치, 자동 투어를 모두 재사용할 수 있습니다.

### 3. 작품 클릭 영역을 실제 작품보다 넓게

3D 공간에서 얇은 액자만 정확히 클릭하게 하면 조작 난도가 높습니다. invisible interaction plane 또는 가까운 거리에서의 highlight로 선택 영역을 넓혀야 합니다.

### 4. 가까이 가면 상호작용 가능함을 보여주기

- 작품 테두리 강조
- 커서 변화
- `작품 보기` 짧은 안내
- 모바일에서는 화면 하단 액션 버튼

상시 설명 UI를 띄우기보다 거리 기반으로 노출하는 편이 몰입과 사용성을 모두 확보하기 좋습니다.

### 5. 미니맵은 ‘길찾기’ 용도로 제한

복잡한 3D 편집기를 만들 필요 없이 관람 시에는:

- 현재 위치
- 작품 위치
- 아직 안 본 작품
- 출구/시작점

정도만 표시하면 충분합니다.

## 캐릭터/조작감에 대한 판단

3D 전시실에서 캐릭터 품질을 높이는 것은 도움이 되지만 **우선순위 1번은 아닙니다**.

먼저 해결할 것:

1. 카메라가 벽에 끼지 않음
2. 이동 속도가 일정함
3. 회전이 과민하지 않음
4. 작품 앞에서 쉽게 멈춤
5. 다음 작품을 찾기 쉬움
6. 모바일에서도 이동 가능

그 다음에:

- 걷기/정지 애니메이션
- 방향 전환 blend
- 점프가 정말 필요한지
- 1인칭/3인칭 전환

을 검토하는 편이 좋습니다.

전시실에서는 점프 기능이 오히려 조작 실수와 멀미를 늘릴 수 있어, 특별한 공간적 이유가 없다면 기본 기능으로 두지 않는 편을 권장합니다.

## 제작기 UX 적용

### 1. 전시실 편집과 관람을 명확히 분리

편집 모드:

- 작품 배치
- 벽/공간 선택
- 작품 크기/높이
- 설명 연결
- 관람 순서 정하기

관람 모드:

- 이동
- 작품 감상
- 설명 보기
- 다음 작품

두 모드의 조작 규칙을 섞지 않습니다.

### 2. 관람 순서는 drag reorder로

3D 공간에서 guide point 순서를 직접 연결하는 것보다 우측 패널에:

```text
1. 민화
2. 테셀레이션
3. 협동화
4. 자유 작품
```

처럼 보이고 드래그로 순서를 바꾸게 하면 교사가 훨씬 쉽게 관리할 수 있습니다.

### 3. 자동 배치 후 미세 조정

학교 전시는 작품 수가 많으므로 한 작품씩 벽에 붙이는 방식만 제공하면 부담이 큽니다.

- 한 벽에 균등 배치
- 방 전체 자동 배치
- 작품 간 최소 간격
- 작품 크기 자동 정규화

후 필요할 때만 수동 수정하는 방식이 적합합니다.

## 그대로 가져오면 안 되는 점

### 1. ‘현실 같은 이동’이 반드시 좋은 UX는 아님

현실 전시장을 그대로 흉내내면 이동 시간이 길어집니다. 웹에서는 순간 이동, 다음 작품, 미니맵 같은 비현실적 도구가 오히려 필요합니다.

### 2. 3D 기능을 전면에 내세우지 않기

놀아트의 본질은 작품 제작·공유·감상입니다. 3D는 감상 방식 중 하나여야지 작품 업로드 자체를 어렵게 만들면 안 됩니다.

### 3. 높은 GPU 요구를 피하기

학교 태블릿과 저사양 PC를 기준으로:

- 그림자 품질 옵션
- texture resolution 제한
- visible artwork culling
- 낮은 polygon 캐릭터
- 전시실 크기 제한

을 고려해야 합니다.

## 구현 실험

### 실험 A1 — guided tour MVP

기존 전시실에 새 3D 모델을 추가하기 전에:

- 작품별 viewpoint
- `다음 작품`
- 0.6~1.0초 이동 보간
- 도착 후 lookAt
- 작품 카드 표시

만 먼저 구현해 조작 체감이 얼마나 좋아지는지 확인합니다.

### 실험 A2 — 입력장치별 프리셋

- PC: WASD + mouse
- 태블릿: 왼쪽 이동 pad + 오른쪽 drag camera
- 접근성: 화면 버튼으로 이전/다음 작품만 사용 가능

### 실험 A3 — 자동 벽 배치

작품 20~30개를 한 번에 넣었을 때 수동 배치 없이 기본 전시가 완성되는 것을 목표로 합니다.

## 판단

- **동선 UX 참고:** 매우 높음
- **놀아트 적용:** 매우 높음
- **Artsteps 자체 기술 스택 참고:** 낮음
- **우선 구현:** 캐릭터 개선보다 guided tour + viewpoint + 모바일 이동
