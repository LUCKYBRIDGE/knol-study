# Padlet — 얽힌 문제 해결

| 문제 | 해결 |
|---|---|
| 학생이 다양한 미디어를 배워야 함 | Post 하나에 attachment 통합 |
| 수업마다 정리 방식이 다름 | Layout 전략 분리 |
| 정렬에 시간 낭비 | 자동 layout |
| 동시에 참여 | realtime product experience |
| 결과만 보면 과정 모름 | Activity |
| 작품과 피드백이 분리 | Comment/Reaction을 Post 옆에 |
| 빠른 입장 필요 | Link/QR |
| 접근 통제 | privacy + visitor permission |
| 자유 활동과 게시판 요구 충돌 | Board / Sandbox 분리 |
| 발표 중 실수로 편집 | Sandbox Play mode |
| 카드마다 참여 범위 다름 | card-level access |

## Knol에 유용
- 작품/학생 결과물 = contribution object
- 표시 방식 = layout
- 피드백 = object context
- 교실 입장 = QR/link
- 작성과 발표 mode 분리

단순 "게시판 UI"만 복제하면 핵심을 놓친다.
