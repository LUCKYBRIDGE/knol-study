# Artsteps / Metasteps — 페이지·UI·UX·버튼

## Creator 흐름
```text
Space 생성
 → 공간 편집
 → + 버튼으로 콘텐츠 추가
 → 배치/크기/회전 조정
 → Info/Guide/Portal 설정
 → Preview
 → Publish
 → Share/Visit
```

## Metasteps Add menu
공식 가이드에서 `+` 버튼으로:
- Images
- Videos
- 3D objects
- 3D text
- Portal
- Info Point
- Web View

### Image
- upload
- Content Library 선택
- title
- optional description/tags/audio

### Portal
- + 버튼
- My spaces 또는 public space 검색
- target 선택
- published viewer에서 통과해 이동

### Info Point
- + 버튼
- title
- description
- external links
- category
- title/category search

### Web View
- + 버튼
- title
- shareable URL
- surface 배치
- top toolbar에서 resize / expand / move

### HyperText
텍스트에 외부 hyperlink 연결.

## Viewer
- 자유 이동
- 작품 접근
- interactive point
- Portal 이동
- guided route
- embedded web interaction

## UX 핵심
3D engine의 mesh/transform/camera 용어보다 작품·설명점·관람 경로·포털 같은 **도메인 언어**를 앞세운다.
