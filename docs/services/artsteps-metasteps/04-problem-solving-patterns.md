# Artsteps / Metasteps — 얽힌 문제 해결

| 문제 | 해결 방식 |
|---|---|
| 일반 사용자가 3D engine을 모름 | 전시 도메인 primitive |
| media 종류가 제각각 | Artifact 개념 |
| 자유 공간에서 길 잃음 | Guide / Guided Path |
| 전시가 단일 방에 갇힘 | Portal |
| 작품 설명이 공간과 분리 | Info Point |
| 외부 퀴즈/설문을 재구현 | Web View |
| 여러 공간 운영 | District/space portfolio |
| private 교육/조직 공간 | membership/role |

## 놀아트 참고 우선순위
1. Artwork와 Viewpoint 분리
2. Guided Path
3. 2D fallback
4. 필요 시 Space/Portal
5. role/organization은 훨씬 뒤

avatar 기능보다 **작품 관람 자체의 접근성**이 우선이다.
