# Excalidraw — 초보자 편집기 UX 심층 검토

검토일: 2026-11-08. **GitHub 공식 기능 목록 기반(A), 사용자 과제 관찰 및 클릭 수 실측은 미실시.**

## 1. 가장 중요한 구분
[Excalidraw README](https://github.com/excalidraw/excalidraw/blob/master/README.md)는 npm 편집기에서 제공하는 기능과 **excalidraw.com에만 있는 기능**을 나누어 설명한다.

| 범위 | 공식 확인 기능 |
|---|---|
| 편집기 패키지 | 도형/선/그리기, 이미지, shape libraries, undo/redo, 줌, .excalidraw JSON export, PNG/SVG |
| 호스팅 앱 | PWA 오프라인, 실시간 협업, E2E 암호화, local-first 자동 저장, 읽기 전용 공유 링크 |

따라서 **편집기 패키지만 설치하면 협업·암호화·local autosave가 전부 자동으로 제공된다고 말하면 오류**다.

## 2. 화면 정보구조로 해석할 패턴
Excalidraw의 실제 UI는 버전·화면 크기에 따라 달라질 수 있으므로 아래 3단계는 **우리 UX를 개선하기 위한 해석·제안**으로 분리한다.
- Always: 현재 과제의 주요 도구.
- Contextual: 선택 객체/모드에 따른 속성.
- Advanced: 파일·공유·레이아웃 고급 설정.

### UI는 버튼 수가 아니라 의사결정 비용으로 평가
'항상 7~9개' 같은 수치는 공식 제품의 규칙이 아니다. 놀아트/놀프린트 사용성 테스트에서 작업 성공률과 발견 가능성을 본 뒤 적절한 버튼 수를 정한다.

## 3. 놀프린트에 적용
사용자 목표는 A4 대형 인쇄다.
```text
작업의 주 흐름
이미지 넣기 → 자르기/맞추기 → 분할 선택 → 미리보기 → 인쇄
```
- 이미지가 없으면 편집 옵션보다 업로드를 강조.
- 이미지가 선택되면 자르기·회전·맞춤만 노출.
- 분할 설정 중에는 매수·여백·겹침만 강조.
- 인쇄 직전 미리보기에는 **실제 페이지 수·용지 방향·양면 해제 확인**.
- 자세한 설명은 필요 시 표시하는 단계적 공개로.

## 4. 놀아트에 적용
- **모드 간 명확한 경계**: 자유그리기 / 테셀레이션 / 협동화 / 3D 전시를 서로 다른 목적의 작업 환경으로 구분.
- **테셀레이션 특수 메뉴**: 옮기기·돌리기·뒤집기, 변형을 도형 선택 상태/모드에 따라 표시.
- **전체화면**: 캔버스 작업 영역이 확대되는 것이 목적이지 설정 화면을 늘리는 것이 아님.
- **모바일**: 속성은 하단 접이식 패널로, 도구와 캔버스 간 pointer event 충돌 회피.
- **입력의 예측 가능성**: 탭/드래그/두 손가락 확대/되돌리기 규칙이 일관되게 유지되어야 함.

## 5. local-first + 파일 포맷의 의미
Excalidraw의 공개 `.excalidraw` 포맷과 browser autosave가 보여주는 원리는 **결과물을 서비스 계정 하나에 가두지 않는 것**이다.
- 내보내기는 JSON schemaVersion, assets 또는 asset references가 함께 있어야 함.
- URL로 다른 기기에 보내는 일과 로컬 브라우저 복원은 전혀 다른 메커니즘.
- 저장본, 공유 링크, 협업 room을 섞으면 읽기 전용인데 수정되는 등 권한 문제가 생김.

## 6. 과제 기반 사용성 실험
초보 교사 3~5명, 학생 3~5명(실제 진행 시 보호·동의 및 개인정보 정책 고려)을 기준으로 개념적인 테스트 계획:
1. 처음 방문한 사용자가 도움 없이 이미지 업로드.
2. 9장 인쇄 미리보기 설정.
3. 실제 인쇄 범위와 분할 수 확인.
4. 실수로 잘못 자르고 복원.
5. 다른 기기에서 작업을 이어가기.
6. 놀아트 테셀레이션 변형 후 전체화면 작업.
7. 터치로 모드 변경, 스크롤, 패널 접기.

**측정값**: 완료율, 잘못 누른 횟수, 힌트 요청, 작업 시간, 결과물 오류. 실측하지 않았으므로 성공률/시간 숫자를 임의로 기록하지 않는다.

## 7. 금지할 오해
- Excalidraw의 UI는 '버튼을 줄이기만 하면 성공'의 근거가 아니다.
- Excalidraw의 PWA/협업/E2EE는 hosted app 기능이며 SDK 자체 기능과 다르다.
- 손그림 시각 스타일을 차용할 필요는 없다. 목표는 편집기 인지부하다.
- 특정 버튼 배치 픽셀을 모방하지 않고 우리 서비스 흐름과 검증 결과를 따른다.

## 8. 라이선스
저장소는 MIT이며 직접 사용하는 라이브러리, 서드파티 자산, 로고·브랜드는 별도 규정을 확인한다. **UI 설계 원리 참고**는 직접 소스 코드 도입과 다르다.

**결론**: Excalidraw에서 가져올 최우선 자산은 '초보 사용자가 작업 맥락에 맞게 핵심 행동을 발견하도록 하는 정보구조'다.
